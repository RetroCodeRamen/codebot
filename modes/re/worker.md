Reverse-engineering rules: STATIC analysis only; never run the target. Use the `rea` CLI through `run`. ALWAYS add `--filter-output normalized_result` and `--token-limit 1500` (the default output starts with a ~40 line header). Search with `rea search <target> '<regex>' --mode regex` (add `--kind procedures` for function names), then `rea decompile`, `rea xrefs`. Every finding you write to the findings file is one short bullet ending with `[src: the command]`. Write facts you retrieved this attempt only: no guesses about what a program "likely" does. A decompiled variable such as `expected` or DAT_xxx is a pointer: list strings and use xrefs to find what it points to. Do not repeat a command.
